# Tarea 1 - Desarrollo de Aplicaciones Web

## Descripcion
Esta tarea incluye la implementacion de una pagina HTML con CSS

## Decisiones Tomadas
- Elegi primero pedirle los datos personales al usuario ya que es lo mas 'obvio' en una pagina de registro
- Elegi que el usuario pudiera elegir entre 1 a 3 actividades para subir ya que dudaba que alguien tenga mas de 3 hobbies que realice de manera activa en horarios estrictos, me parecio la opcion mas realista
- El formato lo elegi de un auxiliar ya que me parecia un formate que funcionaba bien para un form de estas caracteristicas
- Decidi poner los enlaces arriba para que fueran mas visibles
- Elegi que exista un limite de 3 archivos para que puedan subir varios de una actividad o uno de cada actividad dependiendo de cuantas actividades realice el usuario
- Solo se puede poner un enlace ya que no me parecio una informacion muy relevante respecto a las actividades asi que con uno solo me parecio suficiente
- El formato de la lista me parecio el mas intuitivo para una lista que muestra esa informacion, me hubiera gustado ponerle mas empeño al diseño grafico pero no disponia de dicho tiempo
- Las estadisticas las mostre en forma vertical ya que me parecio acorde al contexto, y los enlaces los puse abajo para que no interfieran con la informacion de los graficos
